## 本轮增量验证

- 内置助手输入按记录与版本去重，验证原始上下文超过 140,000 字符的单任务和工作空间仍可问答与生成概览；160 条长文档的相关内容选择、60,000 字符上限、节选披露、完整质量指标、原则基线版本及范围隔离。
- 调用计数只在请求模型时递增；覆盖运行前撤权、取消、密钥解密失败、提供方失败、每日限额、旧版本地拒绝计数的一次性修正，以及保存设置与调用并发时计数不丢失。
- 概览作业去重、任务范围校验、排队/运行/成功/失败状态轮询、读取失败重试、未配置引导及重新生成失败时保留旧结果。问答组件验证选择的任务 ID 实际提交给服务端。
- 浏览器通过隔离数据库和本地 HTTP 模拟模型，验证大任务问答、概览生成、失败提示、旧概览保留及实际请求计数；模型设置页通过 WCAG A/AA 自动检查，概览截图已人工检查。未调用真实付费模型。

- 10 类工程条目的重点关注标记独立持久化，旧数据库自动补字段，重启后保留；不修改版本、更新时间、审批、历史及质量证据。验证只读/跨任务权限、幂等重放、并发内容编辑、拒绝/删除和任务关闭后的取消关注。
- REST 严格布尔输入、关注筛选与分页、MCP 第 10 个工具 `set_record_star` 与筛选参数；插件下载携带更新后的契约。
- 关注按钮防重复提交、失败可重试；集中视图按项目/任务/类型筛选、搜索、状态展示和返回来源。浏览器验证需求/标准/设计/用例的标记与刷新保留、标准深链接展开、拒绝需求回看、45px 桌面列表及 390px 手机布局，并人工检查截图。
- E2E 隔离服务单独设置更高请求配额，容纳一分钟内连续执行多条完整工作流程；正式服务默认 600 次/分钟，登录和初始化的独立限流保持不变。

- 演示场景统一为知识库网站的文章搜索、分类筛选和分页；需求、设计、用例、执行证据、文档与 Claude 插件示例使用一致的通用场景。

- Claude 插件两种下载布局、内部链接与在线契约一致、精确版本示例经 MCP 回放、同输入 ZIP 可复现、Owner/Agent 权限、URL 与来源校验、工作数据和凭证不进入包。
- 插件设置页加载失败重试、下载失败保留输入、不重复下载、剪贴板权限错误、Token/OAuth 切换、HTTPS 约束、浏览器实际下载、390px 手机操作。完整插件验证与边界见 [claude-plugin.md](claude-plugin.md)。

- 需求分组归属、禁止跨任务引用、拒绝/删除/恢复、原因及操作历史、幂等重放、Owner 权限、已关闭任务和版本冲突。
- 需求变化导致执行与人工豁免失效；历史证据不改写；范围外需求退出当前矩阵和待处理列表；混合关联用例按当前标准统计。
