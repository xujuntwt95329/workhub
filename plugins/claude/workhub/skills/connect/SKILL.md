# 连接与任务定位

先读 [接入协议](../../references/protocol.md)。此 Skill 默认只读。

1. 找到当前客户端提供的 WorkHub MCP 工具，读取 `workhub://schema` 和 `workhub://guide`。工具名称可能带插件前缀，以客户端发现的工具为准。
2. 通过 `list_records(kind="task")` 定位用户给出的任务；展示编号 TASK-xxx 要先解析为返回的 UUID。如果标题重复且上下文无法确定，给出候选让用户选择。
3. 调用 `get_task_context(taskId)`，读取目标、当前需求、采用的原则版本、实施、阻塞项及质量缺口。原则来自当前任务；有未采用更新时说明差异，不自行采用。
4. 简要回报已连接的任务编号、当前状态、最重要的缺口，以及后续将处理的用户目标。后续写入始终使用这个任务的 UUID。

连接失败时不要把本地文档视作已经同步。401 提示通过客户端的 MCP 认证入口重新登录或检查 Token 环境变量，具体步骤见包内 README；403 提示核对任务范围和权限；网络失败提示检查下载包中的服务地址。不要读取或回显用户凭证来诊断。

用户仅要求连接时，不创建测试数据、不修改任务、不自动调用付费的内置助手。
